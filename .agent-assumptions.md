- **Scope: "trainers" = the story-mandatory ones.** Gym leaders, Alola's trial captains and island kahunas, the Elite Four, and champions for Gen I–IX. Rivals, evil-team bosses, professors, Battle Frontier brains and Hisui (no gyms) are left out — the title pairs "trainers" with "gym leaders", so the League ladder is the obvious first slice; everything else can be added as more rows.
- **Data is hand-kept in `src/data/trainers.ts`, not fetched.** PokeAPI (the app's data source for locations) has no trainer endpoint, so a typed static list is the only option. It's TS rather than JSON so the type union (`PokemonType`, roles, regions) is checked at compile time.
- **One row per appearance, not per person.** Koga, Bruno, Lance, Wallace, Iris, Hala, Olivia, Acerola and Larry hold two jobs across games; each gets its own slug (`koga`, `koga-elite-four`). The detail page links the others under "Other appearances". Simpler than a nested "appearances" schema and keeps every URL flat.
- **One "ace" Pokémon per trainer instead of full teams.** Full teams differ per game/rematch and would multiply the dataset ~10×; the ace is what gives the list its sprites and its link into `/pokemon/*`. Blue (Gen I champion) has no ace because his differs by starter.
- **Remakes are folded into the original generation.** FRLG sits with Gen I, HGSS with Gen II, ORAS with Gen III, BDSP with Gen IV — the `games` field spells them out. Emerald's Juan / champion Wallace, B2W2's new leaders, and version-exclusive Galar leaders are separate rows.
- **Filters: generation + role + free-text search.** Generation matches the issue ("across gens"); role separates gym leaders from the League. Region is searchable but not a chip, since region ≈ generation here.
- **Routes `/trainers` and `/trainers/[slug]`**, statically generated, with sitemap entries, JSON-LD breadcrumbs/list, and a nav entry (`Medal` icon as `TrainersIcon`) in the desktop extra nav and the phone "more" sheet. The "more" sheet's tools grid now has 7 tiles, so its 2-up layout leaves one empty cell.
- **Tests: `bun run check:trainers`** (`scripts/check-trainers.ts`), following the repo's existing `check:deck-rules` pattern rather than adding a test runner. It verifies unique/url-safe slugs, valid generations and types, badge-only-for-gym-leaders, every ace resolves via `@pkmn/dex` and existed by that generation, and that all nine generations are covered.
- **Checks could not be run in this environment.** Every `bun run …`, `tsc` and `biome` invocation was denied by the sandbox (also when delegated). Code was reviewed by hand for type and import-order/format issues, but please run `bun run check && bun run check:trainers` before merging.
